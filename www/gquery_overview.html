🎯 User Input

Multi-select genes via fuzzy search. Choose perturbation type (All / Chemical only / Genetic only) and set |logFC| cutoff to filter weak signals. Supports custom cutoff values.

⚙️ Query Engine

Uses precomputed fst columnar signature files + qs gene maps. Reads only target gene columns for speed. Searches all 10 data sources and merges with metadata.

📦 Data Sources

Chemical (4): CIGSData, HerbData, LINCS 2020, LINCS L1000
Genetic (6): GuoziData, PerturbAtlas, LINCS 2020 KD/KO, LINCS L1000 KD/KO

📊 Result Tables

Split into Suppressors (effect < 0, ranked by logFC ascending) and Activators (effect > 0, ranked descending). Each further divided by Chemical vs Genetic. Each row has a Download button for full DEG data.

🔬 Detail Modal

Click any Dataset to open a modal with: compound 2D/3D structures (chemical) or STRING PPI network (genetic), full metadata, PubChem/UniProt links, and combined DEG visualization plots.

📈 7 Visualization Plots

Count Bar (Up/Down/NS), CDF Curve (logFC distribution), Volcano (logFC vs -log10 FDR), Manhattan (rank vs -log10 p), Rank Plot (gene vs logFC), Density (logFC density), Lollipop (top 20 genes). Combined via patchwork & downloadable as PDF.
