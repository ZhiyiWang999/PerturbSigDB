Case Study 2. Identifying Chemical Perturbations That Resemble a CDK4 Knockout Signature

Biological question

After characterizing the transcriptional consequences of a genetic perturbation, researchers often want to know whether chemical compounds can induce similar molecular states. Such compounds may phenocopy selected downstream effects of the genetic perturbation, modulate related pathways or provide clues for mechanism-of-action analysis.

Using the CDK4 knockout signature in MCF-7 cells from Case Study 1 as an example, this case study asks:

Which chemical perturbations produce transcriptional effects similar to CDK4 knockout, especially with respect to E2F- and proliferation-associated transcriptional programs?

This example illustrates how Gene Set Query, Gene Query, Perturb Query and Browse can be used together to prioritize and cross-check candidate chemical perturbations.

Step 1. Identify chemical perturbations that suppress the E2F Targets pathway

In Case Study 1, CDK4 knockout in MCF-7 cells showed strong suppression of the E2F Targets gene set. Therefore, we first used the Gene Set Query module to search for chemical perturbations that inhibit the same pathway.

Users open the Gene Set Query module, select Hallmark as the pathway database, choose E2F Targets as the query gene set, set the regulatory direction to Suppress, select Chemical as the perturbation type and click Run.

PerturbSigDB returns perturbation signatures ranked according to their suppressive effects on the selected pathway. Among the top results, several signatures correspond to palbociclib, an FDA-approved CDK4/6 inhibitor. This provides a positive-control-like result, because palbociclib is expected to affect CDK4/6-related cell-cycle transcriptional programs.

In this example, the top-ranked palbociclib signature PSC819792 was selected for further inspection.

Users can scroll down to the Explore Selected Dataset section, enter PSC819792, and select the E2F Targets pathway from the Hallmark collection. PerturbSigDB then generates pathway enrichment results for the selected perturbation signature, including Hallmark enrichment, KEGG enrichment and GSEA visualization for the E2F Targets pathway.

The enrichment results show that the top perturbed pathways of PSC819792 are highly consistent with those observed in the CDK4 knockout signature PSG55550. In particular, the leading suppressed pathways largely overlap between palbociclib treatment and CDK4 knockout.

The enrichment scores of the E2F Targets pathway are also highly similar between palbociclib treatment and CDK4 knockout, with values of approximately −4.108 and −3.716, respectively. These results suggest that PSC819792 produces a pathway-level transcriptional response resembling that of the CDK4 knockout signature.

Because palbociclib is a known CDK4/6 inhibitor, this result mainly serves as a positive control demonstrating that PerturbSigDB can recover a biologically expected chemical perturbation.

To further examine whether PerturbSigDB can identify additional compounds with CDK4-knockout-like transcriptional effects, we next inspected amsacrine, the top-ranked non-CDK4/6 inhibitor in the Gene Set Query results.

In this analysis, the amsacrine signature PSC634846 was selected for further exploration.

Using the same pathway enrichment workflow, users can analyze PSC634846 in the Explore Selected Dataset section. The top Hallmark pathways perturbed by PSC634846 show strong overlap with those observed after CDK4 knockout. Several of the highest-ranked suppressed pathways are shared between the two signatures.

The E2F Targets enrichment scores are also comparable between PSC634846 and CDK4 knockout, with values of approximately −4.241 and −3.716, respectively. These results suggest that PSC634846 induces a pathway-level transcriptional response similar to that of the CDK4 knockout signature.

Step 2. Cross-check downstream gene suppression using Gene Query

Pathway-level similarity can be further evaluated at the gene level. In Case Study 1, PCNA was used as a representative downstream readout of the E2F-associated proliferative transcriptional program and was strongly down-regulated after CDK4 knockout.

Therefore, PCNA provides a useful gene-level marker for cross-checking candidate chemical perturbations.

Users open the Gene Query module, enter PCNA, set the |logFC| cutoff to 2, select Chemical as the perturbation type and search for candidate signatures including PSC819792 and PSC634846.

Both signatures show marked down-regulation of PCNA. The logFC values of PCNA are approximately −9.880 in PSC819792 and −9.314 in PSC634846. This result is consistent with the CDK4 knockout signature and supports the similarity between these chemical perturbations and CDK4 loss at the gene-expression level.

This step illustrates how users can move from pathway-level candidate selection to gene-level validation within the same database.

Step 3. Use Perturb Query to identify globally similar perturbation signatures

Gene Set Query is useful when users are interested in a specific pathway or gene set. However, when a complete perturbation signature is available, users can use the Perturb Query module to compare the full expression profile against curated perturbation signatures in PerturbSigDB.

Here, we downloaded the CDK4 knockout signature PSG55550 from the Browse module and uploaded it to Perturb Query as a gene-logFC table. After clicking Run, PerturbSigDB searched for perturbation signatures with similar or opposite global transcriptional effects.

The top-ranked similar signature was PSC634832, whose perturbagen is amsacrine. This result is consistent with the Gene Set Query analysis, which also identified amsacrine as a compound producing CDK4-knockout-like pathway-level effects.

To further inspect this result, users can search for PSC634832 in the Browse module and perform the same pathway enrichment and GSEA analyses. The top perturbed Hallmark pathways of PSC634832 show strong overlap with those of the CDK4 knockout signature. Several pathways ranked among the top results for PSC634832 also appear among the top enriched pathways in the CDK4 knockout signature.

The E2F Targets enrichment scores are also similar between PSC634832 and CDK4 knockout, with values of approximately −4.475 and −3.716, respectively. These results indicate that PSC634832 produces a transcriptional response comparable to that of CDK4 knockout.

We then used Gene Query to check whether PCNA was also down-regulated in PSC634832. PCNA showed a logFC of approximately −3.947, indicating notable down-regulation and further supporting the similarity between PSC634832 and the CDK4 knockout signature.

4. Interpreting differences between Gene Set Query and Perturb Query

Gene Set Query and Perturb Query may return different top-ranked signatures because they address different analytical questions.

Gene Set Query evaluates whether a perturbation activates or suppresses a selected pathway or gene set. It is most suitable when users only have a pathway of interest, such as E2F Targets, or when they want to identify perturbations that regulate a predefined biological program.

Perturb Query compares a complete gene-logFC signature with all perturbation signatures in the database. It considers the ranked expression pattern across many genes and is therefore more suitable when users have a full differential expression profile.

In this case, Gene Set Query identified PSC634846 as a top amsacrine signature based on E2F Targets inhibition, whereas Perturb Query identified PSC634832 as the most globally similar signature to the CDK4 knockout profile. Both signatures were associated with amsacrine but differed in experimental conditions.

Because PSC634832 was not generated in MCF-7 cells, direct comparison with the CDK4 knockout signature should be interpreted cautiously. We therefore further inspected the Perturb Query results and identified PSC634848, an amsacrine-treated signature generated in MCF-7 cells.

For MCF-7 cells, Gene Set Query retrieved PSC634846, whereas Perturb Query retrieved PSC634848. Both signatures used amsacrine as the perturbagen but differed in dosage or experimental setting. To compare their similarity to CDK4 knockout at the gene level, we examined PCNA downregulation using Gene Query.

PCNA showed a logFC of approximately −4.061 in PSC634848 and −9.314 in PSC634846. Both values indicate marked PCNA suppression. In this comparison, the Perturb Query-derived MCF-7 signature showed a PCNA downregulation level closer to that observed after CDK4 knockout, whereas the Gene Set Query-derived signature showed stronger suppression of the E2F Targets pathway.

Interpretation

This case demonstrates how PerturbSigDB supports reverse discovery from a genetic perturbation signature to candidate chemical perturbations. Starting from the CDK4 knockout profile, users can first search for pathway-level similarity using Gene Set Query, validate downstream gene responses using Gene Query and then perform full-signature comparison using Perturb Query.

The recovery of palbociclib supports the biological relevance of the workflow, because palbociclib is a known CDK4/6 inhibitor and is expected to affect E2F- and cell-cycle-associated transcriptional programs. The identification of amsacrine signatures by both Gene Set Query and Perturb Query further illustrates how PerturbSigDB can nominate compounds that induce transcriptional states resembling selected features of a genetic perturbation.

More generally, this workflow shows how PerturbSigDB connects genetic perturbation signatures with chemical perturbation profiles, enabling users to explore functional similarity between gene loss and compound treatment in a unified transcriptomic space.

Notes

The results should be interpreted as transcriptomic similarity evidence. Similarity between a chemical perturbation and a genetic perturbation does not prove a shared direct target, direct causal mechanism or therapeutic efficacy. In particular, the amsacrine results should be viewed as hypothesis-generating evidence that selected amsacrine signatures resemble aspects of the CDK4 knockout transcriptional response.

Candidate chemical perturbations identified by PerturbSigDB should be further evaluated using drug-target annotations, pathway knowledge, literature evidence, biological context and experimental validation.
